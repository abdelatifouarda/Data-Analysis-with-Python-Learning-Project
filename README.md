# Data Analysis with Python – Learning Project

## 📌 Project Overview
This project is a learning-focused data analysis project built using Python.
The main goal is to practice and demonstrate core data analysis skills such as data cleaning,
data manipulation, data visualization, and a basic machine learning workflow.

This project is intentionally simple and is designed for educational purposes.

---

## 🛠 Tools & Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- Scikit-learn

---

## 📂 Project Structure
- Data loading and inspection
- Data cleaning and preprocessing
- Feature engineering (e.g., grouping continuous variables)
- Exploratory Data Analysis (EDA)
- Data visualization
- Basic Machine Learning model (KNN Classification)

---

## 🔍 Data Analysis Focus
The focus of this project is on:
- Understanding the dataset structure
- Handling missing values
- Transforming and grouping variables for analysis
- Visualizing data using different visualization libraries
- Applying a simple machine learning model to understand the ML workflow

This project does **not** focus on advanced modeling or prediction optimization.

---

## 🤖 Machine Learning
A basic KNN Classification model was implemented to practice:
- Train/Test split
- Feature scaling
- Model training and evaluation

The purpose of using machine learning in this project is **learning the workflow**, not building a production-ready model.
